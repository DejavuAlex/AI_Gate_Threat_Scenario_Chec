# Enterprise AI Knowledge Assistant User Stories

## US-AI-001 Ask a free-form question

As an employee, I enter a free-form AI instruction so that the assistant can answer from authorized enterprise knowledge.

## US-AI-002 Add team knowledge

As a knowledge owner, I perform 上传文档到向量知识库 so that approved content becomes retrieval context.

## US-AI-003 Execute an approved tool

As an authorized requester, I let the agent invoke a business API only after I review and confirm the proposed arguments.

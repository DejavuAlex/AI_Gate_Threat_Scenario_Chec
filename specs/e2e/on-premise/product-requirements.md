# Localized Laboratory Platform Product Requirements

## Scope

The customer installs the platform inside an isolated network and operates a 本地管理控制台 for configuration and support.

系统支持管理员通过本地管理控制台和内网管理门户维护本地化部署。

Administrators import a 离线升级包 from approved removable media. Employees use Active Directory integration and LDAP login with their existing enterprise identities.

系统允许管理员执行离线升级包和离线安装包导入，系统支持用户通过 Active Directory integration 和 LDAP login 完成企业目录认证。

## Success criteria

- The internal administration workflow remains available without Internet access.
- Every update and directory login is attributable to an administrator or employee.

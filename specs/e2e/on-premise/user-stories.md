# Localized Laboratory Platform User Stories

## US-ONPREM-001 Manage an isolated deployment

As a customer administrator, I use the on-premises admin portal from the management network to configure the localized product.

## US-ONPREM-002 Install a validated release

As a release administrator, I import an offline update package from removable media into the isolated deployment.
